# 見つかっている問題（筋の通らない実装）

2026-11-25 に、4 つの領域（ターンと会話の流れ、サーバーとプロトコル、エージェントの道具、翻訳）を読んで洗い出した。各項目の「場所」はその時点のコード（3303da8）。直したら、この一覧から消す（履歴は Git を見る）。

深刻さ：高＝人の知らないうちに、外へ送る・書き換える・お金を使う。中＝使う人が困る・誤解する。低＝改善。
