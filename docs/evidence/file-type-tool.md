# ファイルのパスと種類（MIME）を返す道具

- **対象と範囲：** 指定したファイルについて、パスと種類（MIME。例 `video/mp4`）を返す道具。GUI を作るときに、チャットの中で動画や音声の再生画面を出し分けるのに使う。まだ作っていない。

## 資料（論文の結果）

- Fratantonio et al., "Magika: AI-Powered Content-Type Detection", ICSE 2025 Research Track. arXiv 2409.13768.
  - 方法：ファイルの 3 か所から 512 バイトずつ読む小さな学習モデル。
  - 対象：100 種類を超える形式の、100 万を超えるファイル。
  - 結果：平均 F1 は 99%。著者は、既存の道具より正確だと述べている（要旨には libmagic との数値の比較が無い）。
  - 支えること：種類を決めるとき、拡張子を信じるより中身で判断するほうが正確だという点。
  - 限界：この道具がモデルや GUI の役に立つかは試していない。
- 道具を持つエージェントと持たないエージェントを比べた研究は見つからなかった。
