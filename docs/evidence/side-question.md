# 横からの質問（`/btw`）

- **対象と範囲：**
  - `thread/btw {thread_id, question}`（流し続ける要求）：スレッドの会話（モデルに送るのと同じもの。要約の後なら要約と残りの部分）の後に質問を付けて、スレッドのモデルに 1 回だけ聞く。答えは `delta` で流れ、`completed` の `result.text` に全文が入る。
  - 質問も答えもスレッドに残さない。ターンが動いていても聞けて、ターンは止めない。保存済みのメッセージまでを見るので、動いているターンの書きかけの答えは入らない。
  - 道具は使わせない：モデルへの文で「道具は使えないので呼ばない」と頼む。キャッシュが効くように、スレッドのターンと同じシステムの文と道具の説明を送るが、答えに道具の呼び出しが入っても実行しない（文字だけを答えにする）。
  - 要求の使用量は、スレッドの要求の記録に `purpose: "aside"` として残す（統計に入る）。
  - `cancel` で止められる（`cancelled`）。無いスレッドは `unknown_thread`、空の質問は `invalid_params`。
  - 入力欄の `/btw` をこの要求に変えるのは、画面の役目。サーバーのコマンド（`command/run`）にはしていない。
  - 範囲外・限界：
    - Claude Code の、前の横の質問（新しい 20 件）を次の質問に付ける動きと、質問を道具つきのサブエージェントに回す動きは作っていない。前の質問を付けたいときは、画面が質問に書き込む。
    - 道具の呼び出しだけで文字の無い答えは、空の文字になる。
- **関連ソースコード：**
  - `core/src/turn.rs`：`aside`、`ASIDE_KIND`。
  - `core/src/lib.rs`：`Core::aside`。
  - `server/src/lib.rs`：`ask_aside`。
  - テスト：`server/tests/turn_tcp.rs` の `a_side_question_is_answered_from_the_conversation_and_not_kept`。
- **根拠の状態：** UNSUPPORTED_APPROVED。画面の操作で、効き目を測る学術研究は当てはまらない。調べたのは、ほかのハーネスの実装だけ。
- **ユーザーの承認：** 2026-11-28。
  - 「次の群（あると便利な機能）に進みますか？」に「次の群へ進む」と答えた。
  - 「「/btw」（作業を止めずに横から質問し、答えを履歴に残さない機能）をどう作りますか？」に「道具なしで答えるだけ」（Claude Code と同じ。今の会話だけを見て答える。履歴に残らない）と答えた。
  - 要求の名前と形、道具の説明を送ること、前の質問を付けないことは、作業者（Claude）が決めた。
