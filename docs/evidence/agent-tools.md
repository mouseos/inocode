# 失敗を繰り返さない・禁止を守る・圧縮後も続けるための仕組み

- **対象と範囲：** モデルが使うツール `plan`・`recall`・`lesson`、ツール実行前の規則の検査と保留・事前承認・承認待ちの報告、同じ失敗の繰り返しへの注意、AGENTS.md の読み込み、圧縮後の復元。範囲外：ファイル・シェルなど作業用のツール（後で検討）、教訓の自動の上げ下げ（下記「未実装」）。
- **関連コード：** `core/src/turn.rs`、`core/src/agent_tools.rs`、`core/src/store.rs`（作業一覧の保存）、`server/src/lib.rs`。
- **根拠の状態：** 部分ごと（下表）。A・B・C は UNSUPPORTED_APPROVED。

## 実装上の決定

- 承認時の案では「AGENTS.md と同じ内容の教訓は、その規則に『ここで守られなかった』と記録する」としたが、全文方式では AGENTS.md の規則が個別のノートとして存在しないため、記録先がない。現在は保存せず「規則に従え」と返すだけにしている。
- 要求ごとに付ける状態（作業一覧と教訓）は保存しない。履歴の末尾に一時的に置くだけなので、圧縮の対象にならず、キャッシュされる前方部分も変わらない。
- 規則の検査に失敗したとき（ストアのエラー）は、呼び出しを実行しない。
- 長さ切れで終わった発言の呼び出しは実行せず「出力上限で切れた」と返す。中断・エラーの発言の呼び出しには答えを付けない（送信時に呼び出しごと除かれる）。
- 教訓は、ターンの最初の依頼文で検索し、使用可の状態（`active`）のものだけを最大 3 件出す。モデルの提案は `candidate` で、人が状態を変えるまで出ない。
